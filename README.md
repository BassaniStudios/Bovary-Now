# 🏎️ Bovary Now

Real-time event and session management platform for **Bovary Club Society**.

Bovary Now is designed to keep crew members informed about what is happening now, what is coming next, and what happened at the latest meet.

---

## 📱 What is Bovary Now?

Bovary Now is a lightweight mobile-first platform consisting of:

- 📱 Android App
- 👑 Private Admin Panel
- ⚙️ Backend / API
- 🗄️ Supabase Database
- 🔔 Push Notifications

The platform is intentionally **not a social network** and does not replace Discord.

Its purpose is simple:

> Open Bovary Now and immediately know what is happening.

---

## 🟢 Main Features

### Current Session

The app can display:

- 🟢 Session Active
- 🟡 Starting Soon
- ⚫ No Session Active

When a session is active, members can see:

- Event name
- Event banner
- Description
- Host
- Start time
- Session status

---
